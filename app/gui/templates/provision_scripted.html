Scripted setup

Run this from a shell that already has your AWS admin credentials (AWS_PROFILE or AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY). Admin creds stay in your shell — this container never sees them.

Before you begin

You need the repo checked out on a machine with aws and tofu (OpenTofu) installed, and admin credentials active in that shell. A good bucket name is unraid-backup-<your-account-id> to match the automated mode.

Run this

./setup.sh <bucket-name> <region>

It wraps tofu apply — creating the bucket and a least-privilege IAM user — and prints the runtime key/secret + region/bucket.

What's next

Paste the printed key/secret into Config (or re-run Test & Validate in guided-manual mode). Then set RESTIC_PASSWORD, and create your first backup job from Jobs.
