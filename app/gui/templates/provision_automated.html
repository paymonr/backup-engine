Automated setup

Paste short-lived admin credentials. We read your AWS account, create the bucket with OpenTofu, save the runtime key, and discard the admin creds.

These admin credentials are transient: used for a single tofu apply in this container, never written to disk or logs, and discarded immediately after. Use short-lived keys and delete them afterward.

How to get short-lived admin credentials

Run aws sts get-session-token --duration-seconds 900 with an admin profile, or create a temporary access key on an admin IAM user and delete it right after. Paste the resulting key, secret, and (if any) session token below.

What this does

Runs OpenTofu once to create the bucket (versioning + SSE + all public access blocked + lifecycle rules) and a least-privilege IAM user, then saves that user's key here. Your admin creds are discarded when the run finishes.
