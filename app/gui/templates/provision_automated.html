How do I create an access key?

In the AWS Console (manual):

  1. Open the AWS Console → IAM → Users, and select your user (or one with permission to create S3 buckets and IAM users).
  2. Open the Security credentials tab → under Access keys, choose Create access key.
  3. Choose the Command Line Interface (CLI) use case, acknowledge the recommendation, then Create access key.
  4. Copy the Access key ID and Secret access key (the secret is shown only once — copy both, or download the .csv), and paste them above.

With the AWS CLI:

aws iam create-access-key --user-name <your-iam-user>

Copy AccessKeyId and SecretAccessKey from the output into the fields above (the secret is shown only once).

After provisioning, remove it:

aws iam delete-access-key --user-name <your-iam-user> --access-key-id <AKIA…>

An IAM user can have at most 2 access keys; if you're at the limit, delete an unused one first — aws iam list-access-keys --user-name <your-iam-user>.
