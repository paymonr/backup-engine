Get from "no bucket" to a validated, least-privilege runtime key. Pick the path that fits how much access you want to hand this container.

Before you begin

You'll need an AWS account and access that can create an S3 bucket and an IAM user — either the web console (guided-manual) or admin credentials (scripted / automated). Everything is created in a single region.

Unsure which path? Guided-manual is the safest — it never sees your admin credentials. All three end the same way: a least-privilege runtime key saved to this container.
